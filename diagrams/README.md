# Diagrams

This folder is intended to store Draw.io diagrams used by the project.

Conventions:
- Source files: `diagrams/*.drawio` (XML-based). Prefer the `.drawio` extension when saving from diagrams.net
- Exports: `diagrams/exports/` — auto-generated PNG and SVG images produced by CI

How it works:

- When you add or update `.drawio` files and push to the repository, the GitHub Actions workflow `.github/workflows/drawio-export.yml` runs and uses the `jgraph/drawio-action` to export each `.drawio` to PNG and SVG formats. Exported files are placed in `diagrams/exports` and committed back to the repo when possible.

Editing locally:

1. Open `diagrams/*.drawio` with diagrams.net (desktop app) or the web app (https://app.diagrams.net/).
2. Save changes and commit the `.drawio` sources. The CI will create image exports automatically.

Tips:
- Commit only source `.drawio` files. The exports are generated by CI and can be ignored in local workflows; however, keeping exported images in the repo may help render diagrams in GitHub pages or other static viewers.
- If you want to regenerate exports manually, run the workflow from the GitHub Actions tab (workflow_dispatch) or re-save and push the `.drawio` files.

Security note:
- The export action runs in GitHub Actions environment. If you need to avoid committing exported files back to the repository, remove the commit/push step in `.github/workflows/drawio-export.yml`.
